# Source and quality notes

The registry records the exact originating file and extraction rectangle for each image. The supplied full-resolution lifestyle photograph is preserved in `sources/`; supplied concept boards are preserved in `reference-only/boards/`.

The original concept boards were generated as complete composite images. Their smaller category photographs cannot be extracted at independent full resolution. Small originals remain available, while 512/1024 square versions are explicitly tagged as resampled. This avoids suggesting that enlarging a 150-pixel detail created a genuine 1024-pixel campaign photograph.

Brand files are traced from the transparent wordmark provided in the conversation. Traced contours are retained as scalable SVG and exported as raster PNG/WebP. No fonts are redistributed. Icons are consistent geometric UI paths, not campaign illustration substitutes. The light-sweep and camera loops were rendered from supplied still imagery.

Reference concepts contain generated lettering, product/brand lookalikes, unverified promotional claims and nonfunctional controls. They are review materials, not publish-ready statements. Primary extracted imagery is separated from visible UI text; selected primary crops were visually reviewed and adjusted. Alternate small crops need individual merchandising review. No exhaustive brand clearance or live-store certification was performed.

This ZIP is a real media library, not a finished storefront. Uploading to GitHub does not upload to Shopify, publish a theme, connect checkout, create products, or make image-rendered UI functional.
