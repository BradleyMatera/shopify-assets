# Shopify theme integration checklist

1. Back up the existing Shopify theme before editing.
2. Upload optimized asset derivatives to Shopify Files or theme assets.
3. Add brand assets through theme settings and semantic sections.
4. Map department art to the existing collection handles.
5. Preserve supplier product photography, search, cart, and checkout.
6. Test responsive layouts, contrast, keyboard access, reduced motion, and checkout before publishing.

This repository is an asset library, not a deployed Shopify theme. No Shopify theme changes have been made by these commits.
