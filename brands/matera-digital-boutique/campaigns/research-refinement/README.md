# Boutique creative refinement

This pass replaces generic product-tile messaging with original demonstrations: show the shopper’s decision before asking for a click.

- **Research:** [competitor references](competitor-audit.md), [shopper questions](shoppers.md), [native discovery](discovery.md), [tags and search phrases](hashtags.md), [free acquisition](free-acquisition.md). The competitor sample is 12 first-party creative references and five separate platform case studies. Observed format is not conversion evidence. This is not a census of competitor ads.
- **Production:** [12 revised scripts and quality gate](quality.md), [20 additional shot plans](wave-two.md), and [three finished visual concepts with proof and exact destinations](art/README.md). Scripts and artwork are prepared, not posts or scheduled releases.
- **First tests:** pack-count proof versus a drawer-use demo, then measure-before-buy versus a generic landing message. Use one exact guide destination and one tracked next action per asset. Hold format and destination constant when testing one opener; never attribute impact to a hashtag from a single post.
- **Status:** [social cleanup tracker](social-status.md). Release counts remain separate from creative counts. No future posts were scheduled as part of this pass.
