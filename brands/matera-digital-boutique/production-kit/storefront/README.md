# Storefront media
Open preview/index.html locally for the responsive design proof. It has no checkout, public route or tracking. Four original editorial scenes are generated using the built-in image tool. Styling props must not be presented as exact supplier items. Use supplier-authorized exact-variant images on product pages and ads where the creative makes a product claim.
Retail configuration: install the Liquid hero only in an unpublished duplicate or safely backed-up draft. Upload desktop 1440 and mobile 900 to Shopify Files; select both in the hero. The section uses Shopify CDN transforms and no JavaScript. Link only to the verified collection. Keep real copy as HTML. Desktop and mobile are independently composed. Use small WebP previews for in-theme media and JPG share variants when a platform requires JPEG. Alternate alt text for decorative hero should stay empty; product imagery uses factual per-SKU alt text.
