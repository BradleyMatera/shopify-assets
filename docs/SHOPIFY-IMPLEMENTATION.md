# Shopify Integration Runbook

1. Verify current store ownership and active theme. Do not assume theme ID from another store applies.
2. Back up and duplicate the active theme. Work in an unpublished theme.
3. Inventory collections, actual handles, existing brand, products, checkout, search, apps, policies, and supplier permissions.
4. Upload approved media to Shopify CDN. Keep editable masters in GitHub or dedicated asset storage.
5. Implement responsive sections and srcsets, text overlays in HTML, not baked into images.
6. Preserve product data, pricing, inventory, collection URLs, SEO metadata, cart, checkout, and customer access.
7. Test mobile, tablet, desktop, keyboard, screen readers, contrast, reduced motion, Core Web Vitals, search, filtering, cart, and checkout.
8. Publish only after QA and explicit review of real storefront content.

This repository does not imply that the Shopify store has been edited or published.
