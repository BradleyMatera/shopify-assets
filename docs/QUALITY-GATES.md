# Asset checks and deployment checks

Completed file generation is separate from storefront approval. The asset manifest records file sizes, dimensions and SHA-256 checksums. Generation failures are listed rather than disguised with placeholders.

Review photographs individually for anatomy, object geometry, unwanted lettering and suitability. Review department crops at their intended display size. Check white marks against a dark background. Compare native source dimensions before enlarging anything.

Motion files must decode, have silent audio behavior, loop smoothly and keep a poster fallback. They are animated stills, not independently generated live-action films.

The optional theme code must be checked in an unpublished Shopify theme at mobile, tablet and desktop sizes. Target keyboard access, useful accessible names, visible focus, adequate contrast, reduced motion and functioning product discovery. No compliance certification is implied by this checklist.
