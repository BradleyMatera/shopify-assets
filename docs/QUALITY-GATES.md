# Release Quality Gates

- **Brand**: cohesive visual language, original and rights-cleared, no confusing association with existing retail brands.
- **Imagery**: high fidelity, consistent lighting, proper art direction, verified product representation.
- **Responsive**: deliberate crops and layout at 360, 390, 768, 1024, 1440, 1920 px.
- **Accessibility**: WCAG 2.2 AA target, accessible names, contrast, focus, keyboard, reduced motion, descriptive alt.
- **Performance**: responsive modern image formats, lazy loading below fold, poster-first video, no unnecessary autoplay downloads.
- **Commerce**: correct inventory, product imagery, collection mapping, navigation, search, pricing, cart and checkout.
- **Truth**: no unverified shipping, discounts, supplier endorsements, security guarantees, or fake reviews.
- **Provenance**: licenses, model releases where needed, asset source and approvals.
